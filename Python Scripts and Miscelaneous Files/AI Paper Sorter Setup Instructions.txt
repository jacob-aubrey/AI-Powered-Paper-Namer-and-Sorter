============================
AI Paper Sorter - Setup Guide
============================

This program uses Google's Gemini AI model to read and organize your research papers.
To work correctly, you need two things:
1) An API key (so the AI can work)
2) A config.json file (so the program knows where to put papers)

---------------------------------------
1. Get your FREE Gemini API Key
---------------------------------------
1) Go to: https://aistudio.google.com/app/apikey
2) Sign in with your Google account.
3) Click "Create API key".
4) Copy the key shown (a long string of letters and numbers).

---------------------------------------
2. Save the Key on Your Computer
---------------------------------------
You only need to do this ONCE.

Windows (PowerShell):
---------------------
1) Open the Start menu, type "PowerShell", and open it.
2) Paste this command (replace YOUR_KEY with your actual key):

   setx GEMINI_API_KEY "YOUR_KEY"

3) Close PowerShell.
4) Restart your computer (or at least log out and back in).

Mac / Linux (Terminal):
-----------------------
1) Open Terminal.
2) Paste this command (replace YOUR_KEY with your actual key):

   export GEMINI_API_KEY="YOUR_KEY"

3) To make it permanent, add the above line to your ~/.bashrc or ~/.zshrc file.

---------------------------------------
3. Create the config.json File
---------------------------------------
The program also needs a config.json file in the SAME folder as the .exe.

Example config.json (edit paths to match your system):

{
    "watch_folder": "C:\\Paper Sorter\\ToSort",
    "sorted_folder": "C:\\Paper Sorter\\Sorted"
}

- "watch_folder": the folder the program watches for new PDFs
- "sorted_folder": the folder where sorted/renamed papers will be saved

Notes:
- Use DOUBLE backslashes \\ in Windows paths (as shown above).
- If the folders don’t exist yet, the program will create them automatically.

---------------------------------------
4. Run the Program
---------------------------------------
- Place the config.json file in the same folder as the .exe.
- Double-click the AI Paper Sorter .exe file you received.
- The program will automatically use your API key and folders.

---------------------------------------
5. Troubleshooting
---------------------------------------
- If the program says: "FATAL: GEMINI_API_KEY not set."
  → It means your API key wasn’t set correctly. Go back to Step 2.

- If the program says: "Failed to load config.json"
  → It means the config.json file is missing or not valid JSON. Check Step 3.

- Make sure you copied the API key exactly with no extra spaces or quotes.
