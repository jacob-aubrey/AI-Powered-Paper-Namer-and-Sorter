============================
AI Paper Sorter - Setup Guide
============================

This program uses Google's Gemini AI model to read and organize research papers.

To work correctly, you need:
1) A Gemini API key
2) Folder settings chosen inside the app

---------------------------------------
1. Get your Gemini API Key
---------------------------------------
1) Go to: https://aistudio.google.com/app/apikey
2) Sign in with your Google account.
3) Click "Create API key".
4) Copy the key shown.

---------------------------------------
2. Save the Key on Your Computer
---------------------------------------
You only need to do this once per PC.

Windows PowerShell:

   setx GEMINI_API_KEY "YOUR_KEY"

Close PowerShell and restart your computer, or at least log out and back in.

Mac / Linux terminal:

   export GEMINI_API_KEY="YOUR_KEY"

To make it permanent, add that line to your shell profile.

---------------------------------------
3. Choose Folders in Settings
---------------------------------------
When you first run the app, it will ask you to choose:

- To Sort folder: where new PDFs are copied/watched.
- Sorted papers root: the main folder where organized papers are saved.

You can change these later with the Settings button in the top-right corner.
The app saves these settings on each PC.

---------------------------------------
4. Run the Program
---------------------------------------
Double-click the AI Paper Sorter executable.

The program will automatically use your API key and saved folder settings.

---------------------------------------
5. Troubleshooting
---------------------------------------
- If the program says "FATAL: GEMINI_API_KEY not set."
  Set the API key again and restart.

- If the app asks for folders again
  Choose both folders in Settings and click Save.

- If a PDF is moved successfully
  The bottom log panel will show View Location and View Paper links.
