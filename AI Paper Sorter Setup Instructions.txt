============================
AI Paper Sorter - Setup Guide
============================

This program uses Google's Gemini AI model to read and organize research papers.

To work correctly, you need:
1) Folder settings chosen inside the app
2) A Gemini API key only if you want AI naming

---------------------------------------
1. Choose Folders in Settings
---------------------------------------
When you first sort a paper, the app will ask you to choose:

- To Sort folder: where new PDFs are copied/watched.
- Sorted papers root: the main folder where organized papers are saved.

You can change these later with the Settings button in the top toolbar.
The app saves these settings on each PC.

---------------------------------------
2. Choose a Naming Mode
---------------------------------------
The Settings window has three naming modes:

- Automatic: use AI when a Gemini key exists, otherwise use Basic naming.
- AI: prefer Gemini naming; falls back to Basic if AI is unavailable.
- Basic: use PDF metadata, first-page text, and the original filename.

Basic naming does not require an API key.

---------------------------------------
3. Optional: Set Up AI Naming
---------------------------------------
AI naming uses Google's Gemini API.

1) Open Settings.
2) Click "Get Key".
3) Create a Gemini API key in Google AI Studio.
4) Paste the key into the Gemini API key field.
5) Set Naming mode to Automatic or AI.

Advanced users can also set the GEMINI_API_KEY environment variable.

Windows PowerShell:

   setx GEMINI_API_KEY "YOUR_KEY"

---------------------------------------
4. Run the Program
---------------------------------------
Double-click Lit Sorter 1.0.exe.

Optional:
Turn on Watch and Launch if you want a lightweight background mode to watch the To Sort folder while the main app window is closed.

This uses the same Lit Sorter 1.0.exe file. Windows starts it with --watch, which means it stays quiet in the background until a PDF appears.

When a PDF is created, moved into, or modified in the To Sort folder, watcher mode opens Lit Sorter if it is not already open.

This is off by default. To enable it, open Settings and turn on "Start Watch and Launch at Windows login/unlock."

When enabled, the app creates a Windows Scheduled Task for your user account. It starts Watch and Launch when you log in and when you unlock Windows.

If Windows blocks the Scheduled Task, the app falls back to the Windows Startup folder so Watch and Launch still starts when you log in.

---------------------------------------
5. Troubleshooting
---------------------------------------
- If AI naming is not set up
  Use Basic naming, or add a Gemini key in Settings.

- If the app asks for folders
  Choose both folders in Settings and click Save.

- If the program says "FATAL: GEMINI_API_KEY not set."
  This should no longer block Basic naming. Open Settings to add a key if you want AI naming.

- If a PDF is moved successfully
  The bottom log panel will show View Location and View Paper links.
