AI Paper Sorter — Quick Setup
==============================

For the full guide, troubleshooting, privacy information, and developer instructions,
open README.md. This short file is only a quick first-run checklist.

1. Extract the complete release ZIP before opening the app.
   If the release includes an _internal folder, keep it next to the executable.

2. Open AI Paper Sorter and click Settings.
   Choose two separate folders:
   - To Sort folder: incoming PDF and Word (.docx) documents.
   - Sorted papers root: the library that will receive approved documents.

3. Choose a naming mode.
   - Automatic: AI when a Gemini key is available; Basic otherwise.
   - AI: prefer Gemini, with Basic fallback on failure.
   - Basic: local extraction only; no Gemini key is needed.

   Then choose a Filename style. Smart (recommended) is safest for mixed
   research material. Citation presets and a validated Custom template are
   available when you want a consistent library convention.

4. Optional Gemini setup.
   Click Settings > Get Key, create your own key in Google AI Studio, paste it,
   choose Automatic or AI, then click Save. Never share your key.

   Word-document AI analysis is off by default. Turn on its separate Settings
   checkbox only if you want extracted .docx text sent to Gemini.

5. Sort a document.
   Drag a PDF or .docx file onto the app, review the proposed name, select a
   destination folder, and confirm. You can edit every proposed filename.

6. Optional background watching.
   Settings > Enable Watch & Launch at Windows login/unlock starts a lightweight
   helper while the main app is closed. It is off by default. The To Sort folder
   can always be changed in Settings.

Important limitations
---------------------
- Legacy .doc files must be saved as .docx first.
- Image-only/scanned PDFs need OCR for useful metadata.
- Review suggestions for reports, theses, letters, and other non-journal items.
- The app never overwrites an existing destination file; it adds -1, -2, etc.
- There is no automatic undo. Check the Log for moved-file locations.
- The on-screen log is read-only. Clear Display clears only the window, never
  the saved paper_sorter_log.txt file.
